# Условие ДЗ 07 — AI-агенты и Multi-Agent Systems

## Цель

Спроектировать мультиагентную систему с RAG-пайплайном для автоматизации бизнес-процесса оформления командировок.

## Шаги задания

1. **Выбор паттернов.** Определить необходимых агентов и разделить их ответственность.
2. **Архитектура.** Нарисовать схему взаимодействия агентов и показать, откуда RAG получает политику командировок.
3. **RAG Flow.** Детально описать chunking, embeddings, retrieval и reranking.
4. **Прототип.** Подготовить Colab/LangChain/LangGraph пример, где агент «Менеджер» делегирует задачу агенту «Поисковик» и получает результат.

## Формат сдачи

- схема архитектуры в PNG/PDF или по доступной ссылке;
- Colab notebook с работающим минимальным примером либо псевдокодом.

## Критерии приёмки

- **Single Responsibility:** задачи агентов разделены корректно;
- **RAG:** отражён Vector DB и нюансы поиска;
- **Работоспособность:** код запускается, агенты обмениваются сообщениями.
