16Расчёт ресурсов (Sizing) для приложений и данных
Цели занятия
прогнозировать требования к вычислительным ресурсам (CPU, GPU, RAM) и хранилищам данных;
выбирать оптимальные конфигурации инфраструктуры для минимизации затрат при соблюдении требований к производительности.

Краткое содержание
методология расчёта ресурсов (CPU, RAM, Disk) для stateless/stateful-сервисов, баз данных (SQL, NoSQL, Vector);
влияние RPS, заданного уровня качества, финансовых ограничений и других требований;
расчёт TCO для on-premise;
практика: детальный расчёт ресурсов для всех компонентов учебного проекта для развёртывания on-premise и в облаке.

Результаты
практическое задание;
конспект лекции;
фрейм Калькулятор TCO.

- производить детальный расчёт ресурсов для компонентов проекта при развертывании on-premise и в облаке
