# FATHER Agent Zoo — M0 scaffold

Каждый агент обязан иметь:

- `agent.yaml` — паспорт;
- `prompt.md` — минимальный system prompt;
- `rag.yaml` — retrieval contract;
- `knowledge.yaml` — bindings к KB.

Все текущие агенты имеют статус `scaffold / M0`. Это наличие производственного каркаса, а не заявление о production-ready runtime.

Канонический реестр: `site/data/agent-registry.json`.
