23 Событийно-ориентированная архитектура (EDA) для AI
Цели занятия
проектировать асинхронные, слабосвязанные системы на основе событий для real-time обработки данных и реакции на изменения;
применять EDA для построения масштабируемых AI-пайплайнов и систем принятия решений.

Краткое содержание
принципы EDA;
паттерны (Pub/Sub, Event Sourcing, CQRS);
использование для построения реактивных AI-систем;
практика: проектирование EDA-архитектуры для системы real-time fraud detection.

Результаты
практическое задание;
конспект лекции.

Преподаватель
Дмитрий Фомин

Компетенции
Применять сложные архитектурные паттерны для решения задач масштабирования, потоковой обработки данных (real-time) и построения безопасных гибридных сред:
- проектировать EDA-архитектуру для систем real-time fraud detection
