# Условие домашнего задания

Источник: материалы занятия **«Низкоуровневое проектирование (LLD): компоненты и взаимодействия»**.

## Цели занятия

- детализировать высокоуровневые компоненты до уровня конкретных классов и модулей;
- проектировать API и протоколы взаимодействия между сервисами;
- создавать последовательности диаграмм (sequence diagrams) для ключевых сценариев использования.

## Практическое задание

Разработать LLD для одного из контейнеров:

1. создать **C3-диаграмму (Component diagram)** выбранного контейнера;
2. подготовить **OpenAPI-спецификацию** его API.

В рамках решения дополнительно приложены sequence diagram, BPMN и DFD, чтобы показать не только состав компонентов, но и поток данных/управления.
