# Домашнее задание — Многоуровневое проектирование: от C4 Model до спецификации API

## Цель

Спроектировать многоуровневую архитектуру AI-сервиса с использованием диаграмм C4 и спецификации API для согласования интеграции.

## Контекст

Продолжается работа над собственным проектом OSINT / Due Diligence AI Platform.

## Шаги выполнения

1. **C2 Container Diagram** — показать архитектуру всей системы и выделить минимум:
   - Frontend;
   - Backend;
   - AI Service;
   - Vector DB;
   - SQL DB.
2. **C3 Component Diagram** — провалиться внутрь контейнера `AI Service` и показать внутренние компоненты.
3. **Sequence Diagram** — сценарий «Пользователь запрашивает рекомендацию».
4. **API Spec** — OpenAPI YAML/Swagger для взаимодействия Backend ↔ AI Service, основной endpoint `/get_recommendation`.

## Формат сдачи

- ссылка на доступные диаграммы;
- файл OpenAPI YAML/JSON;
- все артефакты собраны в одной публично доступной папке GitHub;
- дополнительно сформирован единый PDF для проверки.

## Критерии приёмки

1. Диаграммы читаемы и соответствуют нотации.
2. Компоненты C3 соответствуют участникам и шагам Sequence Diagram.
3. OpenAPI содержит:
   - типы данных;
   - примеры request/response;
   - коды ошибок.
