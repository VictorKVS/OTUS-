# BA-001 · Бизнес-анализ SADEQ UAA
**Методическая рамка:** BABOK (структура анализа), BPMN 2.0 (процессы), UML (акторы/состояния), DMN (решения), Value Stream (ценность), Business Model Canvas (гипотезы бизнеса). Модели ниже — **проектные, не результаты интервью**.

## Stakeholders
Заказчик/спонсор: экономика и риски. Пользователь: качество аналитики. Архитектор: контракты и варианты. Владелец данных: ACL и provenance. ИБ: trust boundaries. Эксперт предметной области: нормы решений. Оператор: действия/отмены. Независимый QA: некомпрометированные результаты. Служба эксплуатации: мониторинг и SLA.

## Current state AS-IS (BPMN narrative)
`Событие → разные несвязанные каналы → ручная классификация объекта → поиск регламентов → экспертное решение → ручное действие → частичный аудит`. Риски: пропущенные связи, длительное согласование, дублирование решений, потеря происхождения информации.

## Target TO-BE (BPMN narrative)
`Message start → ingest+validation → entity resolution → record event → derive state → GraphRAG/verified calculation → policy decision (DMN)`.  
При отказе: **STOP/LOG, tool не вызывается**. При требовании согласования: **Wait for human approval**, ветви approve/reject; reject → STOP/LOG. При разрешении: action tool → observe effect → feedback evaluation → finish. Тайм-ауты и аварийные завершения должны быть отдельными ветвями.

## UML use cases
Акторы: Пользователь, Администратор, Эксперт, Аудитор, Корпоративный источник. Кейсы: добавить источник, зарегистрировать объект, выяснить статус, объяснить изменение, получить прогноз, предложить реакцию, согласовать действие, проверить audit, запустить Qualification Lab, отключить агента.

## DMN decision table (минимум)
| Критическое действие | ACL прошёл | Доказательства полны | Проверка политики | Решение |
|---|---|---|---|---|
| любое | нет | любое | любое | DENY |
| высокорисковое | да | любое | любое | NO_AUTONOMOUS_ACTION |
| обратимое низкорисковое | да | да | да | APPROVAL_OR_BOUNDED_EXECUTION |
| любое | да | нет | да | REQUEST_MORE_EVIDENCE |
| любое | да | любое | нет | DENY |

## Business Model Canvas — гипотезы
Ценность: ускорение проверяемых решений, повторное использование ядра, ниже стоимость новой специализации. Сегмент: локальные предприятия/регулируемые отрасли. Каналы: интеграторы, корпоративный пилот. Выручка: лицензия/внедрение/поддержка — гипотеза. Затраты: platform R&D, GPUs, эксплуатация, security qualification, domain adaptation, support.

## KPI и validation
- Time-to-qualified-agent и инженерные часы на следующую специализацию;
- доля результатов, принятых независимой проверкой;
- cost per accepted outcome;
- latency p50/p95, tokens/s, RPS;
- критические ACL bypass: **0 в контрольных испытаниях** (не доказательство абсолютной безопасности);
- время от появления события до рекомендаций;
- business impact measured against manual AS-IS baseline.

## Перед архитектурной приёмкой
Нужны интервью с заказчиками, текущие измерения AS-IS, подтверждённые baseline costs, согласованный value stream и список функций, за которые заказчик готов платить. Без них ROI остаётся моделированием.
