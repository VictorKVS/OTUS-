# IDEA-2026-UAA-001 · Паспорт идеи и контракт требований
**Версия:** 0.2 · **Дата:** 27.11.2026 · **Статус:** RESEARCH.
## Проблема
Каждый отдельный AI-агент обычно создаётся заново: свой prompt, RAG, база знаний, оперативная БД, инструменты, ручное тестирование и логирование. Это повышает затраты на новую специализацию и затрудняет проверку безопасности. Необходима универсальная **инженерная линия**, которая отделяет общее ядро от предметного адаптера.

## Заказчики и целевой рынок
Организации с локальными информационными контурами; инженерные команды, операционные диспетчеры, ИБ, операционная аналитика торговли/медицины. Конкретный заказчик и платежеспособный спрос пока **НЕ ПОДТВЕРЖДЕНЫ**.

## Functional requirements
| ID | Функция | Проверка |
|---|---|---|
| FR-01 | ≥2 типа входных каналов (сообщение / документ / API) | успешный import с source_ref и trace_id |
| FR-02 | Общая идентичность объекта по разным каналам | два наблюдения → один object_id |
| FR-03 | История событий и replay | воспроизведение состояния из event log |
| FR-04 | Обнаружение изменений | positive и negative fixture tests |
| FR-05 | Настоящий GraphRAG | обход связей + доступный проверяемый источник, сравнение с vector-only |
| FR-06 | Нелинейный agent flow | LangGraph transition, checkpoint, retry, bounded loops |
| FR-07 | Прогнозы отдельным кодом | воспроизводимый baseline и backtest |
| FR-08 | Политика до исполнения | запрет несанкционированного tool call |
| FR-09 | Контролируемое обучение | обновления по подтверждённой обратной связи с регрессией |
| FR-10 | 3 отраслевых паспорта | нет копии исходного UAA core |
| FR-11 | Bootstrap agent | формирует patch/tests следующей версии в sandbox, не self-approve |
| FR-12 | Offline | запрет egress, ни одного сетевого вызова во внешнюю сеть |
| FR-13 | RBAC/data ACL | User B не видит секреты A через граф, векторы, кэш, лог |
| FR-14 | Trust qualification | версия агента допускается лишь после независимого evidence |
## Нефункциональные требования
Предметный SLO p95 задаётся после baseline, не придумывается. Аудит, воспроизводимость, договорённость о хранении, изоляция контуров, graceful fail, энергоэффективность и доступность в границах утверждённого SLA.

## MVP
Один локальный runtime; 2 канала, 1 общий объект, 1 state/event rule, 1 безопасный tool/draft action, реальные Qdrant+Neo4j, 1 Agent 001; три различных конфигурации для валидации универсальности. Не включаем автономные высокорисковые действия, обучение весов LLM, гарантии отсутствия галлюцинаций или промышленное масштабирование на 20 агентов.

## Неизвестные
Размер датасета, качество entity resolution, стоимость human review, VRAM/throughput, лицензии моделей, календарь защиты, фактическая точка экономической окупаемости.
