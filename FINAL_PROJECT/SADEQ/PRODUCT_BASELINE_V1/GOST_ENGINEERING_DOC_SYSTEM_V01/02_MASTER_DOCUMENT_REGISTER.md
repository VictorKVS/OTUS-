## Правила ведомости
- В каждом официальном документе определяются юридический/технический владелец, подписанты, договорная применимость, нормативные коды, версия, язык, среда, состав приложений, конфиденциальность.
- `DRAFT` означает только проектное содержимое; `NOT_RUN` и `NOT_MEASURED` нельзя повышать словами.
- На стадии ТЗ согласовать обязательность каждого вида документа, применимость ГОСТ, порядок согласования, число экземпляров, электронный формат, критерии готовности.
- Обновления проходят `Change Request → Impact → Review → Approval → Version → Evidence`. Список должен расширяться, но ID не переиспользуются.
