# PRODUCT-001 — Vision, Value Proposition и Business Case
**Статус:** гипотезы продукта, до customer discovery.

## Видение
**SADEQ** — универсальная инженерная система, создающая, тестирующая и выпускающая агентов. **UAA** — универсальный событийно-аналитический агент со входными каналами, объектной моделью, событиями, доказательным знанием, прогнозированием и управляемой реакцией. Агент состоит из `mission prompt + knowledge base + GraphRAG + operational DB + curriculum + verified feedback + tool contracts + independent tests + runtime monitoring`; промпт никогда не считается контуром безопасности.

## Customer problem и Jobs to Be Done
- **Enterprise IT/ИБ:** «Когда автоматизируем процесс, хочу воспроизводимый audit и гарантию соблюдения настроенных прав, чтобы не создавать новую точку неконтролируемого доступа».
- **Операционный руководитель:** «Когда данные приходят по разным каналам, хочу единое состояние объекта и проверенную рекомендацию, чтобы сократить ручную обработку».
- **AI engineering lead:** «При новой специализации хочу повторно использовать квалифицированное ядро, чтобы не переписывать оркестрацию/хранилище/QA».
- **Оператор риска:** «Когда результат неоднозначен, хочу остановить опасную автоматизацию и увидеть происхождение фактов».

## Сегменты и предложения
A. Регулируемый on-prem: акцент приватности, local inference, ACL, audit.  
B. Предприятия со смешанными событиями (продажи, логистика): state/event intelligence.  
C. Software engineering: агент 001 разрабатывает ограниченный patch следующей версии платформы (human commits and approval).  
D. Разработчики сервисов: SDK для агента, реестр квалификаций, тестовые контракты.

## Value hypothesis
Новый агент требует `ядро + ontology + rules/algorithms + tools + evaluation suite`; при N специализациях общий core окупается, если `C_shared + N*C_adapter < N*C_standalone`. Не обещать экономию, пока не измерены одинаково квалифицированные агенты.

## Business Model Canvas
Сегменты: IT/ИБ руководители, владельцы процессов, интеграторы. Ценность: локальность, traceability, controlled reactions, lower marginal specialization cost. Каналы: демонстрация, референс-пилот, интегратор. Отношения: пилот и SLA support. Выручка (проверить): корпоративная лицензия/инсталляция/поддержка/адаптеры/обучение. Активы: runtime, contracts, test corpus, knowledge engineering. Действия: R&D, qualification, сопровождение моделей и регламентов. Партнёры: поставщики железа, интеграторы, предметные эксперты. Затраты: R&D, GPU/VM, лицензии, SOC, доменные эталоны, SLA и обновления.

## Валидация спроса
Нужны 8–12 структурированных интервью с представителями разных заказчиков как план исследования, не факт; минимум 2 согласованных сценария и baseline ручной обработки; один платёжеспособный пилот до вывода коммерческих прогнозов. Success criteria: подтверждённый pain, юридический permission, измеренные time savings и accepted-result rate.

## Ценностные метрики
`Cost per qualified outcome`; `Time-to-qualified-agent`; share reusable code; staff hours saved under equal quality; time-to-detect change; precision/recall on domain goldens; privacy/security incidents; operational SLO p95.

## Competitive positioning
Не просто чат-бот/секретарь и не только «RAG над PDF». Отличие — нормализованный поток наблюдений об объектах, state and event modeling, выбор реакции по политикам и независимая квалификация. Это позиционирование — **не подтверждённое лидерство на рынке**.
