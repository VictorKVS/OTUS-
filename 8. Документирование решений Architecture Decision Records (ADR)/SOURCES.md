# Источники

Дата обращения: 19 августа 2026 года.

1. Architecture Decision Record — определение ADR, рекомендации по Git, именованию, неизменяемости и последствиям:  
   https://github.com/architecture-decision-record/architecture-decision-record
2. Markdown Architectural Decision Records — структура MADR, варианты, outcome, последствия и confirmation:  
   https://adr.github.io/madr/
3. Andreessen Horowitz, *Navigating the High Cost of AI Compute* — факторы выбора hosted service, cloud GPU и собственной инфраструктуры:  
   https://a16z.com/navigating-the-high-cost-of-ai-compute/
4. ADR GitHub Organization — Decision Capturing Tools, каталог ADR CLI, UI, renderers и архитектурных инструментов:  
   https://adr.github.io/adr-tooling/

Шаблоны FATHER в этой папке созданы самостоятельно на основе общих принципов ADR/MADR. Полные тексты источников не копировались. Числовые сведения из статьи a16z являются историческими и требуют актуализации перед реальным решением.
