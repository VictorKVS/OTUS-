# Урок 6 — C4 Model

Учебный конспект по модели C4 для описания архитектуры программных систем.

Первоисточник: https://c4model.com/introduction

Дата изучения: 2026-08-19.

## Цель урока

- научиться показывать архитектуру от общего контекста до деталей реализации;
- различать уровни `Software System → Container → Component → Code`;
- выбирать диаграмму под аудиторию и задачу;
- создавать понятные связи, подписи, легенду и границы ответственности;
- применять C4 к собственным проектам OTUS и FATHER.

## Краткая формула C4

| Уровень | Что показывает | Основная аудитория |
|---|---|---|
| 1. System Context | Пользователей, исследуемую систему и соседние системы | Все участники |
| 2. Container | Приложения, сервисы и хранилища внутри системы | Техническая команда |
| 3. Component | Крупные функциональные части выбранного контейнера | Архитекторы и разработчики |
| 4. Code | Классы, интерфейсы, функции и таблицы внутри компонента | Разработчики |
