# ГОСТ / ТК 362 — режим хранения в публичном репозитории

Репозиторий `VictorKVS/OTUS-` является публичным.

В этом слое хранятся:

- обозначения стандартов;
- статусные реестры и даты проверки;
- ссылки на официальный Росстандарт / `protect.gost.ru`;
- provenance сторонних mirror-кандидатов;
- локальные SHA-256 после импорта на компьютере владельца.

Полные тексты ГОСТ из сторонних GitHub-зеркал не копируются автоматически в публичный репозиторий без отдельной проверки права на распространение. Наличие PDF в публичном стороннем репозитории само по себе не является доказательством разрешения на повторную публикацию.

Локальная библиотека полных текстов ведется отдельно. Идентичность документа определяется по обозначению внутри документа и SHA-256, а не только по имени файла.

Авторитет для статуса стандарта: Росстандарт (`protect.gost.ru`). Перечень ТК 362 используется как тематический seed, а не как самостоятельное доказательство актуальности каждого документа.
