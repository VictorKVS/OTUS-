# Regulatory Public Corpus

Публичный слой нормативной библиотеки для проекта архитектора.

## Что хранится в GitHub

- карточки федеральных законов с привязкой к официальному порталу правовой информации;
- перечень национальных стандартов ТК 362, используемый для контроля полноты локальной библиотеки ИБ;
- ссылки на официальные реестры статуса и на проверенные upstream/mirror-кандидаты;
- служебные реестры, хеши и provenance.

## Важное разграничение

Репозиторий `VictorKVS/OTUS-` публичный. Полные тексты ГОСТ из сторонних зеркал здесь не переиздаются автоматически без подтвержденного права на распространение. Полные локальные копии стандартов остаются в приватной библиотеке на диске и связываются с этим реестром по обозначению и SHA-256.

Федеральные законы представлены карточками официальных источников. Для юридической работы актуальная редакция должна проверяться на Официальном интернет-портале правовой информации (`pravo.gov.ru`) на дату применения.

## Структура

- `laws/` — федеральные законы и официальные источники;
- `gost/` — ТК 362, статусные реестры и ссылки на Росстандарт;
- `../data/gost_ib_currentness_registry_2026-08-27.json` — проверенный статус локально найденных стандартов;
- `../data/gost_ib_tk362_seed.txt` — 70 полностью восстановленных обозначений из официального перечня ФСТЭК.
