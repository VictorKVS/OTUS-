# FATHER Common Knowledge Core Curriculum

Статус: **CANONICAL DESIGN v1**

Это общая школа всех профессиональных агентов. Специализация начинается только после прохождения K0.

## K0 modules

| ID | Модуль | Что агент должен доказать |
|---|---|---|
| K0-M01 | Sources & Provenance | distinguish source/fact/claim/inference; retain exact source/version references; detect missing provenance |
| K0-M02 | Document Literacy | read structured documents; identify sections/tables/requirements; track document versions and supersession |
| K0-M03 | Analytical Foundations | extract facts/entities/relations/events; separate evidence from hypothesis; detect contradictions and uncertainty |
| K0-M04 | Requirements & Traceability | understand BUS/FR/NFR; link acceptance and risks; trace requirement to decision/test/evidence |
| K0-M05 | AI/RAG/Agent Fundamentals | understand model/prompt/RAG/tool/workflow roles; distinguish knowledge from memory; know evaluator and experiment concepts |
| K0-M06 | Evidence-driven Communication | write structured outputs; cite evidence; state uncertainty; abstain when evidence is insufficient |
| K0-M07 | Security & Permissions | respect access scopes; handle secrets/PII safely; understand tool permissions and audit |
| K0-M08 | FATHER Engineering Standard | follow agent lifecycle; understand Development Pack; use LAB/DevOps/certification gates; preserve evidence |

## Graduation

Общий экзамен `G-K0-GRADUATION` обязателен для всех профессиональных агентов.

После K0 агент не считается специалистом. Он получает право перейти в K1 specialization.

~~~text
K0 SCHOOL
→ G-K0-GRADUATION
→ K1 SPECIALIZATION
→ specialist exam
→ practice
→ certification
~~~

Первые K1 программы:
- ALINA Analytics;
- OSINT;
- FATHER Architect;
- FATHER Programmer;
- далее IB / DevSecOps / Pentest / Legal / Project.
