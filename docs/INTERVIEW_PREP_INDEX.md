# Interview Preparation Pack — AI Systems / LLM / RAG / Security

## Назначение

Этот набор документов превращает блок «Ключевые компетенции» из резюме в проверяемую программу подготовки к собеседованию.

Целевой профиль: **AI Systems Engineer / LLM & RAG Engineer** — Secure AI · AI Agents · Knowledge Systems · Security Requirements · Regulated Environments.

Главное правило: в резюме остаётся только то, что кандидат способен объяснить своими словами, показать на схеме, подтвердить рабочим примером/артефактом и защитить от уточняющих вопросов.

## Структура

1. `INTERVIEW_COMPETENCY_MATRIX.md` — карта компетенций, уровни и evidence.
2. `LLM_RAG_INTERVIEW_PLAYBOOK.md` — LLM, structured output, RAG, retrieval, reranking, GraphRAG.
3. `AGENTS_SECURE_AI_INTERVIEW_PLAYBOOK.md` — agents, orchestration, MCP, memory, tool-use, Secure AI.
4. `BACKEND_AI_ASSISTED_ENGINEERING_PLAYBOOK.md` — Python, FastAPI, asyncio, PostgreSQL, Docker, Git, pytest, CI/CD, AI-assisted development.
5. `SECURITY_COMPLIANCE_ARCHITECTURE_PLAYBOOK.md` — requirements, compliance, access, segmentation, backup, DLP/SIEM/EDR/WAF.
6. `INTERVIEW_EVIDENCE_AND_CLAIMS_POLICY.md` — как не завышать опыт и как формулировать проектную практику.

## Формат изучения

`Concept → 60-sec answer → Diagram → Practical example → Trap questions → Evidence → Ready`

Статусы: `LEARN` — термин понятен, ответ нестабилен; `PRACTICE` — могу объяснить, нужна тренировка; `READY` — могу объяснить, нарисовать и защитить примером; `EVIDENCE` — есть подтверждающий артефакт.

## Сквозные цепочки

AI: `Requirement → Data → Retrieval/Context → Model → Tool/Agent → Validation → Observability → Security → Evidence`

Security / Compliance: `Source → Requirement → Applicability → Gap → Control → Architecture → Implementation → Test → Evidence`

Страница `site/interview-prep.html` показывает этот набор как интерактивную карту подготовки.
