## Как заполнять

Никаких процентов «на глаз». Клетка меняется только после просмотра артефактов:

- `D` — DESIGN;
- `L` — LAB;
- `V` — VALIDATED;
- `P` — PROD;
- `N/A` — неприменимо, есть rationale.

Отдельный evidence file должен объяснять, почему статус повышен.
