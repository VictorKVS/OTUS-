## Wave B — High-value cross-check

Следом прогоняем по фазам:
1. Alina Knowledge Worker;
2. CyberED / Security KB;
3. OSINT_deepseek — **только анализ/картирование, репозиторий не изменяем**;
4. BOOKCRAFT / Makar;
5. Local LLMs;
6. UAG / Universal Agent.

Эта группа даёт максимальное разнообразие: knowledge, security, OSINT, frontend/creative, inference, agents.

## Wave C — Specialized labs

SecGraph, MindForge, Quant, Media, Story Engine, Vibe Coding, DZ18 integrations, Regulatory Twin, DevSecOps Factory, AI Product Architect.

## Wave D — Remaining inventory

Остальные репозитории добавляются после инвентаризации. Они не получают выдуманный статус: сначала discover → classify → map → evidence.

## Выход каждой волны

- заполненная phase matrix;
- gap register;
- reusable pattern candidates;
- duplicated mechanisms list;
- block extraction backlog;
- cross-project benchmark/evidence.
