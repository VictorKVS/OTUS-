# FATHER Combat Project Dossier C00–C99 v2

Статус: **CANONICAL DESIGN v2**

Военный принцип: у каждого проекта один и тот же индекс дел. Код раздела не меняется от проекта к проекту; конкретный проект заполняет содержимое.

**Важно:** `C00–C20` — восстановленное legacy-ядро. `C21–C99` — новая достройка FATHER v2 по текущей архитектуре.

- C80–C89 — DevOps / environments / operations;

## Every section

Каждая папка получает `README.md` с одинаковыми полями:

```text
INPUT
DEPENDENCIES
PROCESS
ARTIFACTS
VALIDATION
EVIDENCE
GATE
FAIL ACTION
OUTPUT
NEXT
```

Таким образом любой проект читается одинаково: неизвестный инженер открывает код Cxx и сразу понимает, где находится приказ/замысел, архитектура, испытания, evidence, эксплуатация и закрытие.
