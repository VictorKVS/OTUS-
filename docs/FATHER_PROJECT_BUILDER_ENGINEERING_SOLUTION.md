# FATHER Project Builder · Engineering Solution

Status: **CANONICAL DESIGN v1**

## Purpose

The first FATHER page is an engineering composition field.

A user writes or speaks one general task. FATHER Factory Controller reads canonical registries and composes a project graph from registered blocks. Unknown capabilities are shown as `NEW_BLOCK_REQUIRED`, never silently invented as production-ready.

## Project flow

```text
GENERAL TASK / PROMPT
        ↓
FACTORY CONTROLLER
        ↓
PROJECT GRAPH
        ↓
BLOCK FIELD / CANVAS
        ↓
CONFIGURE EACH BLOCK
        ↓
RUN / TEST / LAB
        ↓
EVIDENCE + OWNERSHIP
        ↓
GATES
        ↓
OUTPUT
```

## Every block has the same engineering shell

- Identity / version / status
- Input / Output contract
- Configuration
- Tools / integrations
- Metrics
- Tests
- Evidence
- Security / permissions
- Ownership / provenance / rights
- Dependencies / compatibility
