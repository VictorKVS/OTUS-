# Домашняя работа OTUS — урок 1

## Назначение папки

Эта папка содержит только материалы, которые относятся к сдаче домашнего задания преподавателю OTUS.

## Исходные материалы

- `../Шаблон_Бизнес_функциональные_требования_БФТ-252831-0fda99.pdf` — шаблон.
- `../Бизнес_функциональные_требования_Суфлер-252831-d02306.pdf` — выполненные БФТ.

## Что считается сдачей

1. БФТ по выбранному проекту.
2. Верхнеуровневые функциональные требования.
3. Нефункциональные требования.
4. Бизнес-правила.
5. Ограничения, допущения и границы проекта.
6. Краткое обоснование модели контракта.
7. Ссылка на схемы, если они требуются формулировкой задания.

## Чего здесь быть не должно

- внутреннего графа знаний FATHER;
- экспериментальных агентов;
- служебных метрик обучения;
- расширенных производственных документов, не запрошенных преподавателем;
- секретов, персональных данных и рабочих учётных данных.

## Статус

- Исходные БФТ: найдены.
- Машинная проверка: выполнена отдельно.
- Чистый пакет сдачи: требует финальной проверки по точной формулировке задания.
- Решение о сдаче: не принято.
